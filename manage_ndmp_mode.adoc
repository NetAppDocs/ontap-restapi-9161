= Manage NDMP mode
:imagesdir: ./media/

[.lead]
Manage NDMP mode using these endpoints to switch between SVM-scope and node-scope settings. Use them to update NDMP configurations according to your operational requirements.

You can use this API to manage NDMP mode: SVM-scope or node-scope.

=== Examples

Updates NDMP mode to SVM:

----
 PATCH "/api/protocols/ndmp" '{"mode":"svm"}'
----

Updates NDMP mode to node:

----
 PATCH "/api/protocols/ndmp" '{"mode":"node"}'
----
