= Manage SVM peer relationships
:imagesdir: ./media/

[.lead]
Manage SVM peering relationships to establish and oversee connections between storage virtual machines (SVMs). Use these endpoints to create, modify, and delete peer connections as needed for efficient resource sharing and collaboration within your ONTAP environment.

== Managing SVM peers

The SVM peer commands allow you to create and manage SVM peering relationships.

=== SVM peer APIs

The following APIs are used to manage SVM peers:

* GET /api/svm/peers
* POST /api/svm/peers
* GET /api/svm/peers/\{uuid}
* PATCH /api/svm/peers/\{uuid}
* DELETE /api/svm/peers/\{uuid}
