= View and update IPsec configuration
:imagesdir: ./media/

[.lead]
Retrieve and update the IPsec configuration to manage secure communication settings for your network connections. Use these endpoints to check current IPsec status or modify the configuration as required.

== Overview

The following operations are supported:

* GET to retrieve the IPsec status: GET security/ipsec
* Patch to update IPsec status: PATCH security/ipsec
